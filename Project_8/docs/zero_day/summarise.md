| **Adaptive Defense: Zero-Day Attack Detection in NIDS with Deep Reinforcement Learning (DRL)**                   | Detect zero-day attacks dynamically in NIDS using adaptive learning.                                                           | DRL-based IDS that learns traffic patterns and adapts defense strategy; reward-driven anomaly detection.                                                                                | Network traffic datasets (not explicitly IoT-specific)                   | Evaluates DRL agent performance vs supervised ML; measures detection delay, adaptability.                      | DRL model adapts quicker to unseen attacks vs static ML; reduces false negatives.                                                                  | Requires high training time; DRL instability in sparse-reward settings; scalability issues for high-speed networks.                  |
| **An Intelligent Zero-Day Attack Detection System Using Unsupervised Learning**                                  | Build an unsupervised-learning system to detect unknown/zero-day threats without labeled data.                                 | Autoencoders + clustering + anomaly scoring; models implicit normal behavior and flags deviations.                                                                                      | Public IDS datasets (e.g., NSL-KDD, DARPA)                               | Tests AE reconstruction error + anomaly threshold tuning.                                                      | Achieves high zero-day detection accuracy without labeled data.                                                                                    | Not optimized for IoT; lacks robustness evaluation under adversarial settings; limited multistage attack modeling.                   |
| **Detection of Zero-Day Attacks via Sample Augmentation for IoV (2025)** Xu et al.                               | Zero-day attack detection in Internet of Vehicles (IoV) hindered by limited labeled attack data and high false positives.      | **FLCGAN** (Few-shot Learning Conditional GAN) with: multi-generator/discriminator, collaborative focal loss, uncertainty-based sample selection; sample augmentation for rare attacks. | F2MD IoV simulation datasets, including 4 zero-day attack sets           | Extensive ablation studies; Wasserstein distance analysis; comparison with AE, Deep-SVDD, Deep-iForest.        | FLCGAN reduces false positives significantly; best detection rate & lowest latency; sample augmentation covers zero-day distributions effectively. | Computationally heavy; requires careful GAN tuning; needs real vehicular deployment validation.                                      |
