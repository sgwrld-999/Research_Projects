B. PORT CATEGORIZATION (Feature Engineering):
   Original Feature: tcp.dstport (continuous: 0-65535)
   Problem: Too many unique values, hard to learn patterns
   
   Solution: Create tcp.dstport_category (3 categories)
   
   Categorization Logic:
   ```python
   def categorize_port(port):
       if pd.isna(port):
           return np.nan
       elif port <= 1023:
           return 0  # Well-known ports (HTTP, HTTPS, SSH, FTP, etc.)
       elif port <= 49151:
           return 1  # Registered ports (application-specific)
       else:
           return 2  # Dynamic/private ports (ephemeral)
   ```
   
   Apply: df['tcp.dstport_category'] = df['tcp.dstport'].apply(categorize_port)
   Drop: Original 'tcp.dstport' column
   
   Benefit: Reduces dimensionality while preserving port-level information

Result: 45 features with correct types and engineered features

STAGE 4: ENCODING & MISSING VALUE IMPUTATION
---------------------------------------------
Objective: Handle categorical variables and missing data

A. CATEGORICAL ENCODING:
   Method: LabelEncoder (sklearn.preprocessing.LabelEncoder)
   
   Strategy:
   - Identify categorical columns: df.select_dtypes(include=['object'])
   - For each categorical column:
     * If unique values < 10: Apply LabelEncoder
     * If unique values >= 10: Drop column (too high cardinality)
   
   Code:
   ```python
   from sklearn.preprocessing import LabelEncoder
   
   categorical_cols = df.select_dtypes(include=['object']).columns
   label_encoders = {}
   
   for col in categorical_cols:
       if df[col].nunique() < 10:
           le = LabelEncoder()
           df[col] = le.fit_transform(df[col].astype(str))
           label_encoders[col] = le  # Save for inference
       else:
           df.drop(columns=[col], inplace=True)
   
   joblib.dump(label_encoders, 'label_encoders.pkl')
   ```
   
   Low-cardinality examples: tcp.flags (limited flag combinations), 
                            mqtt.msgtype (14 message types)

B. MISSING VALUE IMPUTATION:
   Method: Median imputation (robust to outliers)
   
   Strategy:
   - Calculate median for each numeric column
   - Fill NaN values with median
   - Preserve dataset size (no row deletion)
   
   Code:
   ```python
   df.fillna(df.median(numeric_only=True), inplace=True)
   ```
   
   Rationale:
   - Median > Mean (robust to outliers in network traffic)
   - Preserves distribution better than mode for numeric features
   - No information loss from dropping rows

Result: 45 features, all numeric, no missing values

STAGE 5: CORRELATION-BASED FILTERING
-------------------------------------
Objective: Remove redundant features using correlation analysis

Method: Pairwise correlation matrix with threshold filtering

Process:
1. Compute correlation matrix:
   ```python
   corr_matrix = df.corr().abs()
   ```

2. Extract upper triangle (avoid duplicates):
   ```python
   upper = corr_matrix.where(
       np.triu(np.ones(corr_matrix.shape), k=1).astype(bool)
   )
   ```

3. Find highly correlated pairs (threshold > 0.95):
   ```python
   to_drop = [column for column in upper.columns 
              if any(upper[column] > 0.95)]
   ```

4. Drop redundant features:
   ```python
   df.drop(columns=to_drop, axis=1, inplace=True)
   ```

Threshold Justification:
- 0.95 correlation = 95% linear relationship
- Removes redundancy while preserving information
- Example: tcp.seq and tcp.ack_raw often highly correlated

Output: 
- Correlation matrix saved: Dataset/text_outputs/correlation_matrix.txt
- Feature heatmap: Dataset/plots/feature_correlation_heatmap.png

Result: 45 features (some may be dropped if correlation > 0.95)

METHOD A: MUTUAL INFORMATION (MI) ANALYSIS
-------------------------------------------
Purpose: Measure statistical dependency between features and target label

Theory:
- Mutual Information quantifies how much knowing one variable reduces uncertainty about another
- MI(X, Y) = 0: X and Y are independent
- MI(X, Y) > 0: X provides information about Y
- Higher MI = stronger relationship with attack detection

Implementation:
```python
from sklearn.feature_selection import mutual_info_classif

X = df.drop('Attack_label', axis=1)  # Features
y = df['Attack_label']                # Target (0=Normal, 1=Attack)

# Calculate MI scores
mi_scores = mutual_info_classif(X, y, random_state=42)
mi_scores = pd.Series(mi_scores, index=X.columns)
mi_scores = mi_scores.sort_values(ascending=False)

# Save results
mi_scores.to_csv("text_outputs/mutual_information_scores.txt", 
                 sep="\t", header=["Mutual Information Score"])
```

METHOD B: PCA-BASED FEATURE IMPORTANCE
---------------------------------------
Purpose: Identify features contributing most to dataset variance

Theory:
- PCA finds directions (principal components) of maximum variance
- First PC captures most variance in data
- Features with high absolute loadings on PC1 contribute most to data structure
- Complements MI by capturing intrinsic data patterns

Implementation:
```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# Standardize first (PCA requirement)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Apply PCA
pca = PCA()
pca.fit(X_scaled)

# Extract feature importance from PC1
pca_importance = np.abs(pca.components_[0])
pca_importance = pd.Series(pca_importance, index=X.columns)
pca_importance = pca_importance.sort_values(ascending=False)

# Save results
pca_importance.to_csv("text_outputs/pca_feature_importance.txt",
                      sep="\t", header=["PCA Loading (absolute value)"])
```

Variance Analysis:

METHOD C: COMBINED SCORING APPROACH
------------------------------------
Purpose: Balance discriminative power (MI) and data structure (PCA)

Formula:
Combined_Score = 0.7 × MI_Normalized + 0.3 × PCA_Normalized

Where:
- MI_Normalized = (MI - MI_min) / (MI_max - MI_min)  → [0, 1]
- PCA_Normalized = (PCA - PCA_min) / (PCA_max - PCA_min)  → [0, 1]

Rationale:
- 70% weight on MI: Prioritize features that directly help classification
- 30% weight on PCA: Ensure selected features capture data variance
- Balanced approach avoids overfitting to labels or ignoring data structure

Implementation:
```python
# Normalize scores to [0, 1]
mi_normalized = (mi_scores - mi_scores.min()) / (mi_scores.max() - mi_scores.min())
pca_normalized = (pca_importance - pca_importance.min()) / (pca_importance.max() - pca_importance.min())

# Combined scoring
combined_scores = pd.DataFrame({
    'MI_Score': mi_scores,
    'PCA_Loading': pca_importance,
    'MI_Normalized': mi_normalized,
    'PCA_Normalized': pca_normalized
})

combined_scores['Combined_Score'] = (
    0.7 * combined_scores['MI_Normalized'] + 
    0.3 * combined_scores['PCA_Normalized']
)

# Sort by combined score
combined_scores = combined_scores.sort_values('Combined_Score', ascending=False)

# Select top 20 features
top_20_features = combined_scores.head(20).index.tolist()
```

Selection Criteria:
- Top 20 features by Combined_Score
- Threshold: Natural gap after 20th feature
- Ensures diversity (not all high-MI or high-PCA)

"""
Edge-IIoT Feature Engineering Pipeline
Processes raw network data to 20 selected features

import pandas as pd
import numpy as np
import joblib
from sklearn.preprocessing import MinMaxScaler, LabelEncoder, StandardScaler
from sklearn.feature_selection import mutual_info_classif
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt
import seaborn as sns
import os

# Configuration
INPUT_FILE = "raw_edge_iiot_dataset.csv"
OUTPUT_DIR = "processed_data"

os.makedirs(OUTPUT_DIR, exist_ok=True)
os.makedirs(PLOTS_DIR, exist_ok=True)

# ==============================================================================
print("Stage 1: Loading raw data...")
df = pd.read_csv(INPUT_FILE)
print(f"Loaded {df.shape[0]} rows, {df.shape[1]} columns")

# Define columns to drop
columns_to_drop = [

    'ip.src_host', 'ip.dst_host', 'arp.dst.proto_ipv4', 'arp.src.proto_ipv4',
    # High-cardinality text
    'tcp.payload', 'dns.qry.name', 'mqtt.msg', 'mqtt.topic',
    # Timestamps
    'frame.time', 'frame_date', 'frame_year',
    # Redundant fields
    'tcp.checksum', 'tcp.ack_raw', 'tcp.options'
]

df.drop(columns=columns_to_drop, axis=1, inplace=True, errors='ignore')
print(f"After removal: {df.shape[1]} columns")

# ==============================================================================
# STAGE 3: FEATURE ENGINEERING & TYPE CONVERSION
# ==============================================================================
print("\nStage 3: Feature engineering and type conversion...")

# Convert to numeric
df['tcp.len'] = pd.to_numeric(df['tcp.len'], errors='coerce')
df['dns.qry.name.len'] = pd.to_numeric(df['dns.qry.name.len'], errors='coerce')

# Port categorization
if 'tcp.dstport' in df.columns:
    df['tcp.dstport'] = pd.to_numeric(df['tcp.dstport'], errors='coerce')
    
    def categorize_port(port):
        if pd.isna(port):
            return np.nan
        elif port <= 1023:
            return 0  # Well-known ports
        elif port <= 49151:
            return 1  # Registered ports
        else:
            return 2  # Dynamic ports
    
    df['tcp.dstport_category'] = df['tcp.dstport'].apply(categorize_port)
    df.drop('tcp.dstport', axis=1, inplace=True)
    print("Created tcp.dstport_category feature")

# ==============================================================================
# STAGE 4: ENCODING & IMPUTATION
# ==============================================================================
print("\nStage 4: Categorical encoding and missing value imputation...")

# Label encoding for low-cardinality categorical features
categorical_cols = df.select_dtypes(include=['object']).columns
label_encoders = {}

for col in categorical_cols:
    if col not in ['Attack_label', 'Attack_type']:  # Keep labels as-is
        if df[col].nunique() < 10:
            le = LabelEncoder()
            df[col] = le.fit_transform(df[col].astype(str))
            label_encoders[col] = le
            print(f"Encoded: {col} ({df[col].nunique()} unique values)")
        else:
            df.drop(columns=[col], inplace=True)
            print(f"Dropped high-cardinality: {col}")

joblib.dump(label_encoders, f"{OUTPUT_DIR}/label_encoders.pkl")

# Missing value imputation
numeric_cols = df.select_dtypes(include=[np.number]).columns
df[numeric_cols] = df[numeric_cols].fillna(df[numeric_cols].median())
print(f"Imputed missing values in {len(numeric_cols)} numeric columns")

# ==============================================================================
# STAGE 5: CORRELATION-BASED FILTERING
# ==============================================================================
print("\nStage 5: Correlation-based feature filtering...")

# Separate features and labels
if 'Attack_label' in df.columns:
    y = df['Attack_label']
    X = df.drop(['Attack_label'], axis=1, errors='ignore')
else:
    y = None
    X = df

# Compute correlation matrix
corr_matrix = X.corr().abs()
upper = corr_matrix.where(
    np.triu(np.ones(corr_matrix.shape), k=1).astype(bool)
)

# Find highly correlated features
to_drop_corr = [column for column in upper.columns if any(upper[column] > 0.95)]
X.drop(columns=to_drop_corr, axis=1, inplace=True)
print(f"Dropped {len(to_drop_corr)} highly correlated features")
print(f"Remaining features: {X.shape[1]}")

# Save correlation matrix
corr_matrix.to_csv(f"{OUTPUT_DIR}/correlation_matrix.txt", sep="\t")

# Plot heatmap
plt.figure(figsize=(12, 10))
sns.heatmap(corr_matrix, cmap='coolwarm', center=0, annot=False)
plt.title('Feature Correlation Heatmap')
plt.tight_layout()
plt.savefig(f"{PLOTS_DIR}/correlation_heatmap.png", dpi=300)
plt.close()

# ==============================================================================
# STAGE 6: SCALING & NORMALIZATION
# ==============================================================================
print("\nStage 6: Feature scaling and normalization...")

# MinMax scaling to [0, 1]
scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X)
X_scaled = pd.DataFrame(X_scaled, columns=X.columns)

joblib.dump(scaler, f"{OUTPUT_DIR}/minmax_scaler.pkl")
print(f"Scaled {X_scaled.shape[1]} features to [0, 1] range")

# Save processed dataset
X_scaled.to_csv(f"{OUTPUT_DIR}/processed_training_dataset.csv", index=False)
print(f"Saved: {OUTPUT_DIR}/processed_training_dataset.csv")

# ==============================================================================
# STAGE 7: FEATURE SELECTION (MI + PCA)
# ==============================================================================
print("\nStage 7: Feature selection using MI + PCA...")

# Method A: Mutual Information
if y is not None:
    print("  Computing Mutual Information scores...")
    mi_scores = mutual_info_classif(X_scaled, y, random_state=42)
    mi_scores = pd.Series(mi_scores, index=X_scaled.columns)
    mi_scores = mi_scores.sort_values(ascending=False)
    
    # Save MI scores
    mi_scores.to_csv(
        f"{OUTPUT_DIR}/mutual_information_scores.txt",
        sep="\t",
        header=["Mutual Information Score"]
    )
    
    # Plot MI scores
    plt.figure(figsize=(12, 8))
    mi_scores.head(20).plot(kind='bar')
    plt.title('Top 20 Features by Mutual Information')
    plt.xlabel('Features')
    plt.ylabel('MI Score')
    plt.xticks(rotation=90)
    plt.tight_layout()
    plt.savefig(f"{PLOTS_DIR}/mutual_information_top20.png", dpi=300)
    plt.close()
else:
    print("  Warning: No labels found, skipping MI analysis")
    mi_scores = pd.Series(0, index=X_scaled.columns)

# Method B: PCA
print("  Computing PCA feature importance...")
scaler_pca = StandardScaler()
X_std = scaler_pca.fit_transform(X_scaled)

pca = PCA()
pca.fit(X_std)

# Feature importance from PC1
pca_importance = np.abs(pca.components_[0])
pca_importance = pd.Series(pca_importance, index=X_scaled.columns)
pca_importance = pca_importance.sort_values(ascending=False)

# Save PCA importance
pca_importance.to_csv(
    f"{OUTPUT_DIR}/pca_feature_importance.txt",
    sep="\t",
    header=["PCA Loading (absolute value)"]
)

# Plot PCA variance
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(range(1, len(pca.explained_variance_ratio_) + 1),
         pca.explained_variance_ratio_, 'o-')
plt.title('Scree Plot')
plt.xlabel('Principal Component')
plt.ylabel('Variance Explained')
plt.grid(True)

plt.subplot(1, 2, 2)
cumsum = np.cumsum(pca.explained_variance_ratio_)
plt.plot(range(1, len(cumsum) + 1), cumsum, 'o-')
plt.axhline(y=0.95, color='r', linestyle='--', label='95% variance')
plt.title('Cumulative Variance Explained')
plt.xlabel('Number of Components')
plt.ylabel('Cumulative Variance')
plt.legend()
plt.grid(True)

plt.tight_layout()
plt.savefig(f"{PLOTS_DIR}/pca_variance_analysis.png", dpi=300)
plt.close()

# Method C: Combined Scoring
print("  Computing combined MI-PCA scores...")

# Normalize scores to [0, 1]
mi_norm = (mi_scores - mi_scores.min()) / (mi_scores.max() - mi_scores.min())
pca_norm = (pca_importance - pca_importance.min()) / (pca_importance.max() - pca_importance.min())

# Combined score: 70% MI + 30% PCA
combined = 0.7 * mi_norm + 0.3 * pca_norm
combined = combined.sort_values(ascending=False)

# Select top 20 features
top_20_features = combined.head(20)

# Save combined scores
combined_df = pd.DataFrame({
    'MI_Score': mi_scores,
    'PCA_Loading': pca_importance,
    'MI_Normalized': mi_norm,
    'PCA_Normalized': pca_norm,
    'Combined_Score': combined
})
combined_df = combined_df.sort_values('Combined_Score', ascending=False)
combined_df.to_csv(f"{OUTPUT_DIR}/combined_feature_scores.txt", sep="\t")

# Save top 20 feature list
with open(f"{OUTPUT_DIR}/selected_20_features.txt", 'w') as f:
    f.write("TOP 20 SELECTED FEATURES\n")
    f.write("=" * 60 + "\n\n")
    for i, (feature, score) in enumerate(top_20_features.items(), 1):
        f.write(f"{i:2d}. {feature}\n")
    f.write("\nComma-separated list:\n")
    f.write(','.join(top_20_features.index.tolist()))

# Create final dataset with 20 features
X_final = X_scaled[top_20_features.index]
X_final.to_csv(f"{OUTPUT_DIR}/final_20_features_dataset.csv", index=False)

print(f"\n{'='*70}")
print("FEATURE ENGINEERING PIPELINE COMPLETE")
print(f"{'='*70}")
print(f"\nFinal dataset shape: {X_final.shape}")
print(f"Output directory: {OUTPUT_DIR}/")
print("\nGenerated files:")
print("  - processed_training_dataset.csv (45 features)")
print("  - final_20_features_dataset.csv (20 features)")
print("  - mutual_information_scores.txt")
print("  - pca_feature_importance.txt")
print("  - combined_feature_scores.txt")
print("  - selected_20_features.txt")
print("  - minmax_scaler.pkl")
print("  - label_encoders.pkl")
print("\nPlots generated:")
print("  - correlation_heatmap.png")
print("  - mutual_information_top20.png")
print("  - pca_variance_analysis.png")

# Display top 20 features
print("\nTOP 20 SELECTED FEATURES:")
print("=" * 70)
for i, (feature, score) in enumerate(top_20_features.items(), 1):
    mi_val = mi_scores[feature]
    pca_val = pca_importance[feature]
    print(f"{i:2d}. {feature:30s} | Combined: {score:.6f} | MI: {mi_val:.6f} | PCA: {pca_val:.6f}")
